# Mi Second Brain

Bienvenido a tu vault de Obsidian gestionado por opencode-obsidian.

## Estructura

- **📁 inbox/** - Notas rápidas sin procesar (brain dump)
- **📁 entregas/** - Templates de entrega Azure terminados
- **📁 tracking/** - Tracker de tareas (resumen compacto)
- **📁 daily/** - Daily notes automáticos
- **📁 recursos/** - Comandos, snippets, aprendizajes
- **📁 proyectos/** - Contextos de IA por proyecto
- **📁 templates/** - Templates personalizados

## Uso

Escribe notas libremente en cualquier ubicación. El sistema MCP se encargará de:
- Detectar Azure IDs y organizar automáticamente
- Aplicar templates según el contenido
- Indexar para búsqueda semántica
- Generar daily summaries

## Templates Disponibles

1. **azure-delivery** - Reporte formal de tarea para Azure DevOps
2. **task-tracker** - Resumen compacto para tracking personal
3. **ai-context** - Prompt estructurado para editores IA
4. **daily-standup** - Resumen para daily meetings
5. **bitbucket-pr-standard** - PR completo para features
6. **bitbucket-pr-release** - PR simple para cherry-picks
7. **confluence-release** - Documento de release en Confluence

## Comandos Útiles

- `obsidian_capture_note` - Capturar una nota desordenada
- `obsidian_apply_template` - Aplicar template a nota existente
- `obsidian_search_vault` - Búsqueda semántica
- `obsidian_get_daily_summary` - Resumen del día anterior
- `obsidian_list_deploy_tags` - Listar tags de deploy
